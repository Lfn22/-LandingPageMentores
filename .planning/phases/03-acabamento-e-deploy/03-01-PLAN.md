# Phase 3 Plan 1: Acabamento e Deploy

## Objective

Fechar o v1: página de política de privacidade (LGPD), acabamento de SEO/performance básico na
landing, guia de deploy passo a passo para a Hostinger e um script que empacota os arquivos prontos
para publicar.

## Context

- `app/config/site.php` é a fonte única de marca/conteúdo (ver `.planning/phases/01-.../01-02-SUMMARY.md`).
- `public/index.php` já usa `e()`, `safe_url()`, `valid_hex_color()`, `csp_nonce()` de `app/lib/security.php` e `app/bootstrap.php`.
- `app/.htaccess` (`Require all denied`) já existe no repo, protegendo a camada compartilhada quando ela precisar ficar dentro do `public_html`.
- `public/.htaccess` já bloqueia `.sql/.lock/.md/.example` e nega listagem; cache de 30 dias para assets estáticos.
- Painel admin (`app/views/admin/*.php`) já tem `<meta name="robots" content="noindex, nofollow">`.
- Stack local: Docker em `LPM_PORT=8091` (`MSYS_NO_PATHCONV=1` necessário para curl no Git Bash).
